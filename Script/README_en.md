# Scripts

Analysis notebooks for the Bicing project.

- **`analisis exploratorio.ipynb`** — exploratory analysis run on the **full**
  Bicing dataset (all annual files, 2020–2024).
- **`Sample 10K/`** — code to work with a **10,000-record stratified sample** of
  the Bicing data, used where processing the full dataset in memory was not
  feasible (e.g. heat map generation). Includes the consolidated sample
  (`dataframe_consolidado_sample_10k.csv`), the station reference file and the
  district GeoJSON used for the maps.
