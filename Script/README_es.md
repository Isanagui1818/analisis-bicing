# Scripts

Notebooks de análisis del proyecto Bicing.

- **`analisis exploratorio.ipynb`** — análisis exploratorio realizado sobre el
  conjunto de datos **completo** de Bicing (todos los ficheros anuales, 2020–2024).
- **`Sample 10K/`** — código para trabajar con una **muestra estratificada de
  10.000 registros** de los datos de Bicing, utilizada allí donde procesar el
  dataset completo en memoria no era viable (por ejemplo, la generación de mapas
  de calor). Incluye la muestra consolidada
  (`dataframe_consolidado_sample_10k.csv`), el fichero de referencia de estaciones
  y el GeoJSON de distritos empleado para los mapas.
