# Proyecto final bootcamp It Academy para data analisys:
Este proyecto es un análisis sobre los datos del Bicing de Barcelona (2020-2024), el conjunto de datos de estos años son: 223.036.883 millones de filas. Se realizó un análisis exploratorio de los archivos de diferentes años, eliminando NA, y columnas innecesarias, para poder hacer merge de todos los datos en un solo archivo.
Posteriormente ese archivo archivo conjunto se compilo en formato .parquet, para poder trabajar de forma más eficiente. Una vez llegados al análisis visual con los mapas de calor se creo un sample de 10k de datos aleatorizados, teniendo en cuenta diversos criterios para que la muestra siga siendo representativa del conjunto de los datos, como los barrios, las horas del día y los meses del año.
